## Story 2 — 변환 결과 앞에 고객 성함 / 대화 시작 시간 추가

### [완료] 2-1. 시간 표시 정규식에 캡처 그룹 추가

- `KakaoTalkMessageTimeRegex()`에 `meridiem`, `hour`, `minute` 명명 그룹 추가 (매칭 범위 불변)

### [완료] 2-2. 시간 변환 헬퍼

- `ConvertToTwentyFourHourText(Match)`: 오전12→00, 오후12→12, 오후01→13. 비정상 값이면 빈 문자열

### [완료] 2-3. 고객 성함 추출 헬퍼

- `ExtractCustomerName(paragraph, isFirstMessage)`: `프로필 사진` 줄 바로 다음 줄. 직원 문단/이름 없음이면 null

### [완료] 2-4. `Convert()` 흐름 수정

- 최초로 발견한 고객 이름(`??=`)과 `matches[0]`의 시간으로 `{HH:mm} 채널({성함}) - {기존 변환 텍스트}` 형식으로 조립 (research.md 추가 요구사항 반영, 이름 없으면 `채널`)
- 변환 결과가 없으면 머리말 없이 빈 문자열 반환
- 모객 메시지 및 일반 텍스트 경로는 변경 없음

### [완료] 2-5. 호출부 영향 확인

- `MainWindowViewModel`, `BatchFileConverter` 모두 `Convert()` 결과 문자열을 그대로 사용 → 수정 불필요

- Release 빌드: 경고 0, 오류 0 ✓

### [완료] 3-3. 동작 검증

- 저장소 외부(scratchpad)의 임시 콘솔 프로젝트로 [가상] 시나리오 실행 (저장소에는 포함하지 않음)
- 결과
  - 오후01:05 시작 → `13:05 채널(홍길순) - [ 눈 ] / ...`
  - 오전12:10 시작 → `00:10 채널(홍길순) - ...`
  - 오후12:10 + 직원 문단 → `12:10 채널(홍길순) - [ 코 ] / ...`
  - `프로필 사진` 없음 → `11:05 채널 - [ 코 ] / ...`
- 미검증: 강남언니 메시지 회귀는 해당 경로 코드를 수정하지 않아 별도 실행하지 않음

4. 정규식 허용 범위 → plan.md 표대로 적용
